# คู่มือผู้ดูแล (ร่างสำหรับหัวข้อ "การส่งมอบ" ในรายงาน ปรับให้ตรงกับผู้รับช่วงจริง)

## ผู้ใช้จัดการยาเอง
เมนู "ยาของฉัน" เพิ่ม แก้ไข หยุดชั่วคราว หรือลบยาได้ ตารางวันนี้และประวัติอัปเดตให้เอง

## ผู้ดูแลระบบ (แอดมิน)
- เมนู "แอดมิน" ดูจำนวนผู้ใช้ ยา และการกินยารายวัน
- เมนู "รายการยา" แอดมินเพิ่ม/แก้/ลบรายการยาแนะนำได้
- ตั้งผู้ใช้ให้เป็นแอดมิน: Supabase → SQL Editor รัน `update public.profiles set role = 'admin' where email = 'อีเมล';`
- ลบผู้ใช้: Supabase → Authentication → Users

## อัปเดตเว็บเอง 3 ขั้น
1. แก้ไฟล์ในโปรเจกต์ แล้วรัน `npm run build`
2. เข้า Netlify (บัญชีของทีม/หน่วยงาน) → โปรเจกต์เดิม → แท็บ Deploys
3. ลากโฟลเดอร์ `dist` ไปวาง รอ Published แล้วกด Ctrl+F5

## ข้อตกลงการใช้ (แก้ตามจริง)
ทีมนักศึกษาเป็นเจ้าของโค้ดตามที่รายวิชากำหนด ผู้รับช่วงนำไปใช้และแก้ไขต่อได้เพื่อประโยชน์ของชุมชน โดยไม่ใช้ข้อมูลผู้ใช้เพื่อการอื่น
