## ปัญหาและกลุ่มเป้าหมาย
ผู้สูงอายุและลูกหลานได้ยาหลายตัวจากโรงพยาบาล ต้องตั้งนาฬิกาปลุกทีละเม็ดด้วยมือ เสียเวลาและตั้งผิดได้
เว็บนี้ให้กรอกยาครั้งเดียว ระบบสร้างตารางประจำวัน เตือนตามเวลา บันทึกว่ากินแล้ว และเตือนเมื่อยาใกล้หมด ใช้ผ่านเบราว์เซอร์ ไม่ต้องติดตั้งแอป

## เทคโนโลยีที่ใช้
Vue 3, Vite, Vue Router, Supabase (Auth, Postgres + RLS, Storage, Realtime), Netlify

คอมโพเนนต์ที่ใช้ซ้ำ: FormField, StatCard, DoseRow, MedCard, ReminderModal · สถานะกลางอยู่ที่ `src/store.js`

## วิธีติดตั้งและรัน
1. ติดตั้ง Node.js รุ่น LTS
2. สร้างโปรเจกต์ Supabase แล้วเปิด `database/schema.sql` คัดลอกเนื้อหาทั้งไฟล์ไปวางใน SQL Editor แล้วกด Run
3. คัดลอก `.env.example` เป็น `.env.local` แล้วใส่ `VITE_SUPABASE_URL` และ `VITE_SUPABASE_KEY` (Publishable/anon key)
4. Authentication → Users → Add user (ติ๊ก Auto Confirm User) สร้างบัญชีผู้ใช้ทดสอบ และบัญชีแอดมินทดสอบ
5. ตั้งบัญชีแอดมิน: รันใน SQL Editor `update public.profiles set role = 'admin' where email = 'อีเมลแอดมิน';`
6. `npm install`
7. `npm run dev` แล้วเปิด http://localhost:5173
8. Deploy: `npm run build` แล้วลากโฟลเดอร์ `dist` ไปวางที่แท็บ Deploys ของโปรเจกต์ Netlify (มี `_redirects` แล้ว)

## ข้อจำกัดที่ควรรู้
- แจ้งเตือนในเว็บทำงานเมื่อเปิดเว็บค้างไว้ ถ้าปิดเว็บให้ใช้ไฟล์ปฏิทิน .ics
- ระบบเป็นเครื่องมือช่วยจำ ไม่ใช่คำแนะนำทางการแพทย์
- ใช้ข้อมูลสมมุติเท่านั้น ห้ามใส่ชื่อหรือข้อมูลสุขภาพจริงของบุคคล
